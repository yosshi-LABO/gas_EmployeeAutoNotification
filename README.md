# gas_EmployeeAutoNotification

このスクリプトは従業員が退職した時に、各種システムのアカウント削除を促すように
システム関係者に通知するスクリプトです。

1.人事システムのデータ(もしくは退職日記入の従業員情報)をインポート
2.他システムのアクティブアカウントと突合
3.関係者へ処理結果通知
